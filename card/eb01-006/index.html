FAQ

How many versions of EB01-006 are there?

Our database lists 5 English printings of EB01-006 Tony Tony.Chopper: 2 Manga, 1 Normal, 1 Parallel (AA), 1 Promo. Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the EB01-006 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

Is the PRB-01 EB01-006 the same as the original?

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check. TCGplayer notes that the PRB-01 Manga was reprinted without the original textured foil.

Which EB01-006 version is the most valuable?

Of the versions OPChase tracks with enough sales, the Manga from Extra Booster: Memorial Collection has the highest PSA 10 anchor ($5,102, from the last same-spec sales). Other versions show 'Price data insufficient' when there are fewer than 5 recent same-spec sales.

How many EB01-006 PSA 10s exist?

GemRate's PSA population mirror (as of 2026-09-28) shows 2,532 PSA 10 copies across the 4 English versions we could match to a PSA spec. See the table for each version.

Who illustrated EB01-006 Tony Tony.Chopper?

Limitless TCG credits kito for the base printing. Parallel artworks can have different illustrators.
