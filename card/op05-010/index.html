FAQ

How many versions of OP05-010 are there?

Our database lists 6 English printings of OP05-010 Nico Robin: 1 Normal, 1 Anniversary Tournament, 1 Foil (reprint set), 1 Full Art, 1 Reprint, 1 Promo. Each one is a separate collectible (and a separate PSA spec when graded).

Is the PRB-01 OP05-010 the same as the original?

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check. On the card, community sources say the original OP05 print has a pen icon next to the illustrator name and PRB-01 reprints lack it.

Who illustrated OP05-010 Nico Robin?

Limitless TCG credits Hashimoto Q for the base printing. Parallel artworks can have different illustrators.
