FAQ

How many versions of OP15-118 are there?

Our database lists 3 English printings of OP15-118 Enel: 1 Normal, 1 Parallel (AA), 1 Manga. Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the OP15-118 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety. English parallels from OP04 onward also show a star above the rarity (community source).

Which OP15-118 version is the most valuable?

Of the versions OPChase tracks with enough sales, the Manga from Adventure on Kami's Island has the highest PSA 10 anchor ($1,004, from the last same-spec sales). Other versions show 'Price data insufficient' when there are fewer than 5 recent same-spec sales.

How many OP15-118 PSA 10s exist?

GemRate's PSA population mirror (as of 2026-09-28) shows 1,520 PSA 10 copies across the 3 English versions we could match to a PSA spec. See the table for each version.

Who illustrated OP15-118 Enel?

Limitless TCG credits AKIRA EGAWA for the base printing. Parallel artworks can have different illustrators.
