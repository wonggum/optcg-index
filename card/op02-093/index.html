FAQ

How many versions of OP02-093 are there?

Our database lists 3 English printings of OP02-093 Smoker: 2 Normal, 1 Parallel (AA). Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the OP02-093 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

How many OP02-093 PSA 10s exist?

GemRate's PSA population mirror (as of 2026-08-25) shows 656 PSA 10 copies across the 3 English versions we could match to a PSA spec. See the table for each version.
