FAQ

How many versions of OP08-105 are there?

Our database lists 3 English printings of OP08-105 Jewelry Bonney: 1 Normal, 1 Parallel (AA), 1 Promo. Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the OP08-105 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

Which OP08-105 version is the most valuable?

Of the versions OPChase tracks with enough sales, the Promo · Illustration Box EX from One Piece Promotion Cards has the highest PSA 10 anchor ($558, from the last same-spec sales). Other versions show 'Price data insufficient' when there are fewer than 5 recent same-spec sales.

How many OP08-105 PSA 10s exist?

GemRate's PSA population mirror (as of 2026-09-27) shows 932 PSA 10 copies across the 3 English versions we could match to a PSA spec. See the table for each version.

Who illustrated OP08-105 Jewelry Bonney?

Limitless TCG credits Daisuke Enoshima for the base printing. Parallel artworks can have different illustrators.
