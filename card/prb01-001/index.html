FAQ

How many versions of PRB01-001 are there?

Our database lists 2 English printings of PRB01-001 Sanji: 1 Normal, 1 Parallel (AA). Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the PRB01-001 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

Is the PRB-01 PRB01-001 the same as the original?

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check.

What is a PSA 10 PRB01-001 worth?
