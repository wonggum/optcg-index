FAQ

How many versions of OP01-003 are there?

Our database lists 3 English printings of OP01-003 Monkey.D.Luffy: 2 Normal, 1 Parallel (AA). Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the OP01-003 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

Which OP01-003 version is the most valuable?

Of the versions OPChase tracks with enough sales, the Alternate Art (AA) from Romance Dawn has the highest PSA 10 anchor ($5,509, from the last same-spec sales). Other versions show 'Price data insufficient' when there are fewer than 5 recent same-spec sales.

How many OP01-003 PSA 10s exist?

GemRate's PSA population mirror (as of 2026-09-28) shows 1,150 PSA 10 copies across the 2 English versions we could match to a PSA spec. See the table for each version.
