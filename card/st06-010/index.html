FAQ

How many versions of ST06-010 are there?

Our database lists 5 English printings of ST06-010 Helmeppo: 1 Normal, 1 Foil (reprint set), 1 Full Art, 1 Reprint, 1 Promo. Each one is a separate collectible (and a separate PSA spec when graded).

Is the PRB-01 ST06-010 the same as the original?

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check.

Who illustrated ST06-010 Helmeppo?

Limitless TCG credits BISAI for the base printing. Parallel artworks can have different illustrators.
