FAQ

How many versions of EB03-055 are there?

Our database lists 3 English printings of EB03-055 Nico Robin: 1 Normal, 1 Parallel (AA), 1 SP. Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the EB03-055 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

Which EB03-055 version is the most valuable?

Of the versions OPChase tracks with enough sales, the SP from Extra Booster: One Piece Heroines Edition has the highest PSA 10 anchor ($1,880, from the last same-spec sales). Other versions show 'Price data insufficient' when there are fewer than 5 recent same-spec sales.

How many EB03-055 PSA 10s exist?

GemRate's PSA population mirror (as of 2026-09-28) shows 2,082 PSA 10 copies across the 3 English versions we could match to a PSA spec. See the table for each version.

Who illustrated EB03-055 Nico Robin?

Limitless TCG credits BISAI for the base printing. Parallel artworks can have different illustrators.
