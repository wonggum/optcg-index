Collector & player notes

Versions

Nami OP01-016 has more than ten English printings: base and Alternate Art in OP01, an SP in OP05, a PRB-01 Manga, an SP in EB05, Gift Collection 2023 and English 1st Anniversary Set promos, and deck reprints. Each graded version is filed under its own PSA set line, so check the label's set line TCGGR.

Seen in decklists (Limitless TCG)

Leaders of the recent Limitless TCG decklists that include this card: Whitebeard OP02-001 (344), Law OP01-002 (248), Zoro OP01-001 (225), Rayleigh OP12-001 (90), Luffy ST01-001 (58), Luffy ST10-002 (36). Counts are the number of listed decklists, as shown on the card's Limitless page.

FAQ

How many versions of OP01-016 are there?

Our database lists 13 English printings of OP01-016 Nami: 4 Normal, 3 Promo, 2 Parallel (AA), 2 SP, 1 Reprint, 1 Manga. Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the OP01-016 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

Is the PRB-01 OP01-016 the same as the original?

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check. On the card, community sources say the original OP01 print has a pen icon next to the illustrator name and PRB-01 reprints lack it. PRB-01 copies of OP01 alternate-art and SEC cards also carry a 'ONE PIECE CARD GAME' stamp at the bottom left that the originals lack (community sources).

Which OP01-016 version is the most valuable?

Of the versions OPChase tracks with enough sales, the Manga from Premium Booster -The Best- has the highest PSA 10 anchor ($2,977, from the last same-spec sales). Other versions show 'Price data insufficient' when there are fewer than 5 recent same-spec sales.

How many OP01-016 PSA 10s exist?

GemRate's PSA population mirror (as of 2026-09-28) shows 12,881 PSA 10 copies across the 6 English versions we could match to a PSA spec. See the table for each version.
