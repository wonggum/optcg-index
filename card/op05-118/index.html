FAQ

How many versions of OP05-118 are there?

Our database lists 4 English printings of OP05-118 Kaido: 2 Parallel (AA), 1 Normal, 1 Reprint. Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the OP05-118 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

Is the PRB-01 OP05-118 the same as the original?

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check. On the card, community sources say the original OP05 print has a pen icon next to the illustrator name and PRB-01 reprints lack it.

Who illustrated OP05-118 Kaido?

Limitless TCG credits SENNSU for the base printing. Parallel artworks can have different illustrators.
