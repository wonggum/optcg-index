FAQ

How many versions of OP06-069 are there?

Our database lists 5 English printings of OP06-069 Vinsmoke Reiju: 2 Parallel (AA), 1 Normal, 1 Reprint, 1 Promo. Each one is a separate collectible (and a separate PSA spec when graded).

How do I tell the OP06-069 Alternate Art from the base card?

The Alternate Art (parallel) uses different artwork with a foil finish and keeps the same card number. On a PSA slab the variety line says ALTERNATE ART; the base card has no variety.

Is the PRB-01 OP06-069 the same as the original?

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check.

Who illustrated OP06-069 Vinsmoke Reiju?

Limitless TCG credits SHIE NANAHARA for the base printing. Parallel artworks can have different illustrators.
