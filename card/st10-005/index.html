FAQ

How many versions of ST10-005 are there?

Our database lists 4 English printings of ST10-005 Jinbe: 1 Normal, 1 Foil (reprint set), 1 Reprint, 1 Promo. Each one is a separate collectible (and a separate PSA spec when graded).

Which ST10-005 version is the most valuable?

Of the versions OPChase tracks with enough sales, the Promo · English Version 1st Anniversary Set from One Piece Promotion Cards has the highest PSA 10 anchor ($212, from the last same-spec sales). Other versions show 'Price data insufficient' when there are fewer than 5 recent same-spec sales.

How many ST10-005 PSA 10s exist?

GemRate's PSA population mirror (as of 2026-09-09) shows 1,996 PSA 10 copies across the 2 English versions we could match to a PSA spec. See the table for each version.

Who illustrated ST10-005 Jinbe?

Limitless TCG credits S-KINOKO for the base printing. Parallel artworks can have different illustrators.
