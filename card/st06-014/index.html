How many versions of ST06-014 are there?

Our database lists 4 English printings of ST06-014 Shockwave: 2 Foil (reprint set), 1 Normal, 1 Reprint. Each one is a separate collectible (and a separate PSA spec when graded).

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check.
