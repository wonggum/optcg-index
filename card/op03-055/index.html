FAQ

How many versions of OP03-055 are there?

Our database lists 6 English printings of OP03-055 Gum-Gum Giant Gavel: 2 Foil (reprint set), 1 Normal, 1 Pre-Release, 1 Reprint, 1 Promo. Each one is a separate collectible (and a separate PSA spec when graded).

Is the PRB-01 OP03-055 the same as the original?

No. One Piece The Best (PRB-01) reprints are separate printings: PSA files them under the PRB01 set line, so the set line on the label is the reliable check. On the card, community sources say the original OP03 print has a pen icon next to the illustrator name and PRB-01 reprints lack it.
