FAQ

How many English One Piece Card Game sets are there?

OPChase lists 65 English sets and products: 18 booster sets, 6 extra and premium boosters, 39 starter decks and 2 promo and other products. Each one has its own set page, newest first on this page.

What is the newest One Piece TCG set in English?

The Dominance of God (OP18), with an English release date of November 20, 2026. Before it: Extra Booster: One Piece Heroine's Edition Vol. 2 (EB05), October 30, 2026, and Set Sail Deck Set (SD01), September 18, 2026.

What was the first English One Piece Card Game booster set?

Romance Dawn (OP01) is the earliest booster set on this page, with an English release date of December 2, 2022. Starter decks ST01, ST02, ST03 and ST04 have the same date.

Which card is shown for each set?

Booster sets, extra and premium boosters and promotion cards show the first card with an image in their set page's top chase cards, a list that puts rarer version types first. Starter decks show their Leader card. A set with no card image yet shows its set code instead.

What does PSA 10 versions tracked mean?

It counts the English versions in that set that have a PSA label line on OPChase, the same figure as PSA 10 versions on the set page. Sets with none yet, such as a set that is not out, show No PSA 10 versions tracked yet.

Where are Pre-Release, Anniversary and Release Event cards?

Event-stamped cards from Pre-Release, Anniversary Tournament and Release Event groups are listed on the page of the set they belong to, not as separate sets.
