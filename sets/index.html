About this database

Built from the TCGplayer English catalog (one product per printing), cross-checked against Limitless TCG, with PSA labels and population from GemRate. Text data only, no card images. Unknown values are shown as unknown. Each set page lists every printing in the product; each card page lists every English version of that card number, how to tell them apart, PSA 10 population and, where OPChase has enough sales, the PSA 10 price. The official product page has been transcribed for OP01, OP05, OP09, OP13, EB02 and PRB01; other sets say so where they are not cross-checked with the official site.

Event-stamped groups (Pre-Release, Anniversary Tournament, Release Event) are shown on their parent set page. Groups with no cards in the catalog yet: OP18-RE (The Dominance of God Release Event Cards), OP-CS (One Piece Collection Sets).
