Kaido OP17-062: four versions and how the PSA label reads

OP17-062 is a purple SR Kaido (cost 10) with four versions: base, parallel, manga parallel and a guest-art Super AA.

By OPChase Research · Published 2026-10-26 · 4 min read

Short answer. OP17-062 is a purple SR Kaido (cost 10) with four versions: base, parallel, manga parallel and a guest-art Super AA. Bandai's official OP-17 list has 4 entries for OP17-062 Kaido card list. On an English slab, read line 1 (OP17 EN), the number (#062) and the variety line, then the code on the card.

What gets confused with it

  • "Super" does not mean manga here. The store name "Super Alternate Art" is the guest-art card, not the manga card.
  • Other Kaido cards in OP-17: OP17-042 (blue R), the OP17-058 Leader and OP17-063 (also a purple SR). Match name and number.
  • SPECIAL ALTERNATE ART on other Kaido slabs: a Japanese OP05 #044 Kaido slab carries the same words (cert 105946891). Line 1 and the number separate it.
