Luffy "#119" PSA slabs: one number, several different cards

On the slabs we checked, a Luffy slab marked #119 was the OP09-119 SP printed in OP-13, the OP05-119 manga version, or a Japanese anniversary-set card. Read the first line, the variety and the code on the card.

By OPChase Research · Published 2026-10-15 · 5 min read

Short answer. A Monkey D. Luffy slab marked "#119" can hold several different cards, so check three things: the first line of the label (year, set code and the EN or JP tag), the variety line, and the card code printed at the bottom right of the card itself (for example OP09-119 or OP05-119; the label shows only "#119"). On the five Luffy slabs we checked, the same "#119" covered an SP card whose code is OP09-119, a manga version of OP05-119, and Japanese-text OP05-119 cards from an anniversary set PSA. The label shows the digits of the card number only. The prefix is on the card, not on the slab label PSA.

What separates them

  1. The set code on the first line is not the card's own code. The two OP13 slabs hold a card whose code reads OP09-119, with an SP mark. Bandai's official card list has OP09-119 as a version in OP-13 card list. On the two slabs we checked, PSA's label gives the set as OP13, the product this version was printed in PSA.
  2. The variety line names the version. "SPECIAL ALTERNATE ART" is the OP09-119 SP on the OP13 slabs we checked. "MANGA ALTERNATE ART" is the OP05-119 manga version on the OP05 slab we checked PSA.
  3. The language tag is at the end of the first line. On the slabs we checked, 'OP13 EN' and 'OP05 EN' held English cards. The two anniversary-set slabs read "2025 ONE PIECE JP", and the cards in them have Japanese text PSA.
  4. The anniversary set name points the other way. On those two slabs, the line where a variety would normally go reads "EN 2ND ANNIVERSARY SET", yet the cards are Japanese. Their cert pages show the set as "ONE PIECE JAPANESE ENGLISH VERSION 2ND ANNIVERSARY SET" and no variety PSA. Go by the first-line tag and the card text, not the set name. Not every "#119" is Luffy

The number is shared across characters too. The label "2026 ONE PIECE OP14-EB04 EN / DRACULE MIHAWK / #119" (cert 153384310) holds a Dracule Mihawk card whose code reads OP14-119, and it has no variety line PSA. Read the name line as well as the number.

How to check a "#119" slab

  1. Read the name line. Luffy or someone else.
  2. Read the first line: year, set code, and EN or JP at the end.
  3. Read the variety line to the end, or note that there isn't one.
  4. Look at the card in the slab. The code at the bottom right (OP09-119, OP05-119, …) tells you which card it is.
  5. Look the cert up at psacard.com/cert/<number> and check that the year, set, character, number, variety and grade match the slab in your hand PSA.

Method and limits

  • How we checked:
    • Label wording comes from PSA's cert pages (psacard.com/cert/<number>), read on 2026-10-09, compared with the front photo of each slab on the same page; slab photos re-checked 2026-10-12.
    • We read the card code at the bottom right of each card in those photos, and the card text language on the two anniversary-set slabs.
    • Card numbers and product names come from Bandai's official English card list card list.
    • All cited certs are publicly viewable. None of them belongs to OPChase.
  • What this guide is not: it is not authentication. A correct label does not prove the slab or card is genuine; always check the cert on PSA's site. It does not cover grading counts or market values.
  • Known gaps:
    • This guide covers only the five Luffy '#119' slabs we checked; other slabs may exist that we have not looked at.
    • We checked one manga slab and two SP slabs. PSA wording on other slabs of the same versions may differ.
