How to read a One Piece PSA label: set line, number and variety

Three things settle most label questions: the language tag, the card-number prefix printed on the card, and the variety line. Cert examples checked on PSA's own cert pages, including the places where the label is misleading.

By OPChase Research · Published 2026-10-12 · 9 min read

Paid links: we earn a commission if you buy through these eBay links.

Short answer. To identify a One Piece PSA slab, check three things: the language tag at the end of the label's first line (EN or JP; newer labels have it, early labels don't), the card-number prefix printed on the card itself (for example OP05-119; the label only shows "#119"), and the variety line (for example SPECIAL ALTERNATE ART).

The rest of the label:

  • First line: the year, "ONE PIECE", usually a set code, and on newer labels a language tag.
  • Number (for example "#062"): only the digits of the card number.
  • Set line: which product the card came from.
  • Variety line: which version it is (alternate art, manga, special, event, winner…).

Then look the cert number up on PSA's site. The cert page shows the same card, but it often writes the set name differently from the printed label. Both are genuine PSA wording PSA.

The printed label and the cert page (one example)

For cert 175297710, the printed label and PSA's cert page read like this PSA:

Part Printed on the label Shown on the cert page (psacard.com/cert/175297710) What it tells you
Year 2026 Year: 2026 The year PSA files the product under
Set line ONE PIECE OP17 EN Brand/Title: ONE PIECE OP17-THE WORLD'S STRONGEST WARRIORS The product (booster OP-17). The label uses the short code plus a language tag; the cert page spells out the product name
Character KAIDO Subject: KAIDO The character
Variety SPECIAL ALTERNATE ART Variety/Pedigree: SPECIAL ALTERNATE ART The version
Number #062 Card Number: 062 Only the digits; the "OP17-" prefix is not printed
Grade GEM MT 10 Item Grade: GEM MT 10 The grade

The cert number (175297710) is printed on the label too. That's the number you look up.

Early labels look different. Early slabs can carry an older label format with no language tag, where the set code sits on the same line as the variety. The one we checked: cert 77206786 (OP01 #003 Monkey D. Luffy, English card) is labelled "2022 ONE PIECE / MONKEY D. LUFFY / OP01-ALTERNATE ART / #003". Its cert page shows Brand/Title "ONE PIECE OP01-ROMANCE DAWN" and Variety "ALTERNATE ART" PSA. Newer labels carry the language tag, including newer slabs of 2022 cards (for example "2022 ONE PIECE OP01 EN", cert 150661075). The label format depends on when the slab was made, not on the card's year.

Bandai's English card OP17-062 Kaido comes in more than one version card list. PSA files the guest-artist version as SPECIAL ALTERNATE ART under the OP17 set line PSA. A Japanese manga-art Kaido slab (cert 178182518) is filed under a different variety, MANGA ALTERNATE ART PSA.

Label vs cert page: more examples we checked

The printed label shortens the set name. The cert page shows the full product name. A mismatch like this is normal PSA wording and is not, by itself, a sign of a fake slab PSA.

When you compare a slab with its cert page, match the meaning, not the exact characters. "PRB01 EN" on the label and "PRB01-PREMIUM BOOSTER -ONE PIECE CARD THE BEST-" on the cert page are the same set line.

Key points for telling cards apart

  1. The number is only digits; read the prefix on the card. PSA prints and stores only the digits of the card number. The PRB-01 Manga version of Portgas.D.Ace is card OP02-013, but its label reads "#013" and the cert page reads "013" (cert 104027989) PSAcard list. An OP13 "#119" label can be OP09-119 (the SP version printed in OP-13) or OP13-119, and the label can't tell you which PSAcard list. Bandai also reuses card numbers across products and versions card list. Read the full card number printed on the card itself, together with the set line and the variety.

  5. Event promos. On the cert page, the three English event promos below have the set line "ONE PIECE PROMOS", and the variety names the event. None of their printed labels has the word "PROMOS"; each first line reads only "[year] ONE PIECE EN" PSA:

    • Super Pre-Release Luffy #001: label "2022 ONE PIECE EN / MONKEY D. LUFFY / SUPER PRE-RELEASE / #001" (cert 154974632).
    • Luffy #135: label variety "OP16 RELEASE EVENT-WINNER" (cert 173291185).
    • Sabo #001: label variety "2ND ANN TOURNAMENT-WINNER" (cert 143888832). PSA writes "2ND ANN" the same way on the label and on the cert page.
    • These are the only promo labels we have checked. Read the variety to the end: the "-WINNER" suffix is part of the version.

  6. Errata. Bandai has issued errata (corrected card text) for some cards rules. PSA puts the errata in the variety as a suffix. The English OP01 #003 Luffy alternate art exists under two separate varieties in the same set line:

    • "ALTERNATE ART-ERRATA", label "2022 ONE PIECE OP01 EN / MONKEY D. LUFFY / ALTERNATE ART-ERRATA / #003" (cert 150661075).
    • Plain "ALTERNATE ART" (cert 77206786). This one has an early-format label, "2022 ONE PIECE / MONKEY D. LUFFY / OP01-ALTERNATE ART / #003", with no language tag. The cert page shows Variety "ALTERNATE ART".

    Read the variety to the end PSA.

  7. Language: trust the first-line tag and the card text, not the anniversary set name. On newer labels, the language tag sits at the end of the first line, after the set code. Early labels have no language tag (see cert 77206786 above), so for those slabs read the card text. Examples on newer labels: "OP17 EN" for English, and "OP05 JP" for the Japanese OP05 Kaido, whose cert page says "ONE PIECE JAPANESE OP05-AWAKENING OF THE NEW ERA" (cert 105946891) PSA. The 2nd Anniversary Sets are a trap because the product names contain a language word that points the other way. We checked the card faces of three public slabs PSA:

    Cert Label first line Set name on the label Cert page (Brand/Title) Card we saw on the slab Card text
    162198453 2025 ONE PIECE JP EN 2ND ANNIVERSARY SET ONE PIECE JAPANESE ENGLISH VERSION 2ND ANNIVERSARY SET Monkey D. Luffy, OP05-119 SEC Japanese
    145793496 2025 ONE PIECE JP EN 2ND ANNIVERSARY SET ONE PIECE JAPANESE ENGLISH VERSION 2ND ANNIVERSARY SET Monkey D. Luffy, OP05-119 SEC Japanese
    145860825 2025 ONE PIECE EN JP 2ND ANNIVERSARY SET ONE PIECE JAPANESE 2ND ANNIVERSARY SET Kaya, OP03-044 English
    • The slabs show only "#119" and "#044". The prefixes OP05-119 and OP03-044 are what we read on the cards themselves.
    • The language tag at the end of the label's first line matched the card text on all three slabs. "JP" = Japanese text, "EN" = English text.
    • The set name is what misleads. "EN 2ND ANNIVERSARY SET" held Japanese-text cards. "JP 2ND ANNIVERSARY SET" held an English-text card. The cert page says "JAPANESE" in both set names.
    • On these labels, the set name sits on the line where a variety would normally be. The cert pages show no variety for these cards.
    • For anniversary sets, read the label's first line and the text on the card, and don't go by the set name.

  8. Merged English sets. Bandai's English products OP14-EB04 and OP15-EB04 combine Japanese sets card list. PSA uses the merged names:

    • Cert page "ONE PIECE OP14-EB04-THE AZURE SEA'S SEVEN" / label "OP14-EB04 EN" (cert 153384310).
    • Cert page "ONE PIECE OP15-EB04-ADVENTURE ON KAMI'S ISLAND" / label "OP15-EB04 EN" (Boa Hancock #014 SPECIAL ALTERNATE ART, cert 161495482) PSA.

  9. Confirm on PSA, not on third-party tools. Look the cert number up at psacard.com/cert/<number>. Check that the year, set line, character, number, variety and grade match the slab in your hand. Allow for the label's shortened set name PSA.

Method and limits

  • How we checked:
    • Every label wording in this guide comes from PSA's own cert pages (psacard.com/cert/<number>), read on 2026-10-09. We compared the cert-page fields with the front photo of the slab shown on the same page.
    • For the three 2nd Anniversary Set slabs we also read the card text and card number in those photos.
    • Cert 178182518 (Japanese slab) was read on 2026-10-08.
    • Cert 77206786 was checked the same way: we compared its cert page with the front photo of the slab. The photo shows an early-format label without a language tag.
    • Card numbers and product names come from Bandai's official English card list.
    • All cited certs are publicly viewable. None of them belongs to OPChase.
  • Printed label vs cert page:
    • The printed label shortens the set name (for example "PRB01 EN", "OP05 JP"). Newer labels add a language tag. The early label we checked (cert 77206786) has none and prints the set code with the variety ("OP01-ALTERNATE ART"). The three English promo labels we checked do not print "PROMOS". The cert page shows the full product name.
    • In every example we checked, the character and number matched between label and cert page. So did the variety wherever the cert page had one; on the early label the variety follows the set code ("OP01-ALTERNATE ART").
    • The 2nd Anniversary Set slabs have no variety on the cert page. Their labels print the set name on the line where a variety would go PSA.
  • What this guide is not: it is not authentication. A correct label does not prove the slab or card is genuine; always check the cert on PSA's site. It does not cover grading counts or market values.
  • Known gaps:
    • PSA label formats change over time; cert 77206786 shows one older format. Our examples are slabs of cards dated 2022 to 2026 only.
    • The promo and anniversary-set observations cover only the slabs listed above.
    • Products that are not out yet (EB-05, OP-18) are not covered.
